# Imperial Development Center

This is a project for IriusRisk test assessment to show the different categories provided by [SWAPI](https://swapi.tech/).

---

## 🚀 Getting Started

Follow these steps to get the project up and running:

### 1. Install Dependencies

```bash
npm install or yarn install
```

### 2. Start Development Server

```bash
npm start or yarn start
```

### 3. Open in Browser

In case it hasn't opened a browser window automatically visit http://localhost:5173

---

## 🛠 Tools Used

- **React**: A JavaScript library for building user interfaces.
- **Vite**: A fast build tool for modern web projects.
- **TypeScript**: A strongly typed programming language for JavaScript.
- **Sass**: A CSS extension language.
